# Genesis 紙プロトタイプ作成メモ v0

最初のテストでは、カードをきれいに作る必要はない。

紙に必要な情報だけ書いて、すぐ遊ぶ。

## カードに書く情報

クリーチャー:

```text
名前
文明 / クリーチャー / コスト
パワー
効果
```

呪文:

```text
名前
文明 / 呪文 / コスト
効果
```

## 例

```text
火花の走り手
火 / クリーチャー / 1
1000
効果なし
```

```text
火弾
火 / 呪文 / 2
相手のパワー3000以下のクリーチャーを1体破壊する。
```

## 作り方

1. `docs/starter-decks-v0.md` を開く。
2. デッキリストの枚数ぶんカードを作る。
3. 効果が分からないカードは `docs/cards-v0.md` を見る。
4. キーワードが分からない場合は `docs/glossary.md` を見る。

## 最初は省略してよいもの

- イラスト
- フレーバーテキスト
- レアリティ
- カード番号
- 細かいレイアウト

## 最初に省略しないもの

- 名前
- コスト
- 種類
- パワー
- 効果
- 枚数

## 最初の調整候補

プレイ後、次を優先して見る。

### 火自然が強すぎる場合

- `火弾` を3枚に減らす。
- `踏み越え` を3枚に減らす。
- `焦熱の大牙` を1枚に減らす。

### 火自然が弱すぎる場合

- `焦熱の大牙` を3枚に増やす。
- `炎圧の先導者` を4枚に増やす。
- `火花の走り手` が弱いなら、パワーを2000にする。

### 水光が強すぎる場合

- `白壁の守護者` を3枚に減らす。
- `光の拘束` を3枚に減らす。
- `水の記録` を3枚に減らす。

### 水光が弱すぎる場合

- `光盾の見習い` のパワーを2000にする。
- `返し波の術士` の対象をコスト3以下にする。
- `静かな再起` を3枚に増やす。

## 調整のルール

一度に大きく変えない。

1回のテストで変えるのは、カード1種類かルール1つまで。

何を変えたかは `docs/playtest-log.md` に残す。
