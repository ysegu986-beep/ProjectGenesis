# Genesis プレイテスト手順 v0

この手順は、最初の紙プロトタイプを遊ぶためのもの。

目的は勝敗を決めることではなく、Genesis の基本体験が面白いかを確認すること。

## 使うもの

- `docs/game-spec-v0.md`
- `docs/starter-decks-v0.md`
- `docs/glossary.md`
- メモできるもの

カードは紙に手書きでよい。

カード名、コスト、パワー、効果だけ分かれば遊べる。

## 遊ぶ前に決めること

最初の数戦は、次の設定で遊ぶ。

- 先攻1ターン目はドローなし
- マナ支払いには文明一致が必要
- 盤面上限なし

この設定は確定ではない。

まず基準になる遊び心地を作るための仮ルール。

## テストする問い

1戦ごとに、次を確認する。

- マナに置くカードで悩んだか。
- シールドを攻撃するか迷ったか。
- 守る側に逆転の可能性があったか。
- カードの強さだけで勝敗が決まっていないか。
- 片方のデッキだけが明らかに有利すぎないか。
- 使わないカードが多すぎないか。

## 1戦の流れ

1. 3つのスターターデッキから使う2つを選ぶ。
2. 先攻後攻をランダムに決める。
3. 各プレイヤーは5枚引く。
4. 山札の上から5枚をシールドにする。
5. `docs/game-spec-v0.md` のターン構造に従って遊ぶ。
6. 試合後、`docs/playtest-log.md` に記録する。

## 記録するときのコツ

「面白かった」だけで終わらせない。

どの場面が面白かったかを書く。

例:

> 5ターン目、火自然側が大型を出すか除去を構えるかで迷った。ここは良かった。

「つまらなかった」だけで終わらせない。

何が判断を消したのかを書く。

例:

> 水光側がブロッカーを並べた後、火自然側に突破手段がなく、3ターン同じ展開になった。

## 最初の3戦で見ること

### 1戦目

ルールが最後まで回るかを見る。

バランスは気にしすぎない。

### 2戦目

先攻後攻を入れ替える。

同じデッキでも体験が変わるかを見る。

### 3戦目

気になった未決定ルールを1つだけ変える。

例:

- 先攻ドローあり
- 文明一致なし
- 盤面上限7体

一度に複数変えない。
