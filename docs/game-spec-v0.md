# Genesis ゲーム仕様 v0

これは、Genesis の最初に遊べる仕様書。

完成版のルールブックではない。テスト用の文書。遊んで弱い体験が出たら、その問題を記録して直す。

## 目指す体験

Genesis は、2人対戦のカードゲーム。

状況を読み、いつ攻めるかを決め、限られたリソースをどう圧力に変えるかを楽しむゲームにする。

最初のプロトタイプでは、デュエマに近い基本構造が Genesis の目指す体験をまだ生めるかを確認する。

## 対戦準備

- プレイヤー: 2人
- デッキ枚数: 40枚
- 初期手札: 5枚
- 初期シールド: 山札の上から5枚
- 初期マナ: 0枚
- 先攻: プロトタイプではランダムに決める

未決定:

- 先攻は最初のターンにドローするか。

これは慣習で決めず、テストして決める。

## 主なゾーン

### 山札

プレイヤーの裏向きのカード束。

カードを引く必要があるときに山札がなければ、そのプレイヤーは負ける。

### 手札

プレイしたり、マナに置いたりできるカード。

プロトタイプ初期設定:

- 手札上限なし

理由:

手札管理の圧力は、まずカード選択とテンポから生ませたい。手札上限のルールで急いで作らない。

### マナゾーン

ここに置いたカードはリソースになる。

プロトタイプ初期設定:

- 1ターンに1枚、手札からマナゾーンに置いてよい。
- マナのカードはタップしてコストを支払う。
- タップしたマナ1枚につき、コスト1を支払う。

理由:

マナは、今カードを使うか、未来のターンに投資するかという中心的な判断を作る。

### バトルゾーン

クリーチャーを出す場所。

プロトタイプ初期設定:

- クリーチャー数の上限はまだ設けない。

未決定:

- Genesis は最終的に盤面上限を持つべきか。

盤面の読みやすさとゲームテンポをテストしてから決める。

### シールドゾーン

各プレイヤーは5枚のシールドから始める。

シールドがブレイクされたら、そのカードは持ち主の手札に加える。

理由:

シールドは逆転の緊張を生み、攻撃をただのライフレースではなく判断にする。

### 墓地

使い終わったカードや破壊されたクリーチャーを置く場所。

## カードタイプ

プロトタイプ v0 では、まず2種類から始める。

### クリーチャー

バトルゾーンに残り、攻撃できるカード。

基本情報:

- 名前
- コスト
- パワー
- 文明
- テキスト

プロトタイプ初期設定:

- 出したターンのクリーチャーは攻撃できない。
- クリーチャーは相手プレイヤーを攻撃できる。
- クリーチャーはタップされている相手クリーチャーを攻撃できる。

### 呪文

一度だけ効果を発揮し、その後墓地に置かれるカード。

基本情報:

- 名前
- コスト
- 文明
- テキスト

## ターン構造

各ターンは次の順番で進む。

1. スタートステップ
2. ドローステップ
3. マナステップ
4. メインステップ
5. アタックステップ
6. エンドステップ

## スタートステップ

ターンプレイヤーのタップされているカードをすべてアンタップする。

## ドローステップ

ターンプレイヤーはカードを1枚引く。

未決定:

- 先攻1ターン目のドローをなくすか。

## マナステップ

ターンプレイヤーは、手札から1枚をマナゾーンに置いてよい。

これは任意。

## メインステップ

ターンプレイヤーは次の行動ができる。

- コストを支払ってクリーチャーを召喚する。
- コストを支払って呪文を唱える。
- メインステップで使える能力を使う。

プロトタイプの支払いルール:

- カードのコストと同じ枚数のマナをタップする。

未決定:

- 支払いに文明一致を必要とするか。

最初のテストでは簡略化してもいい。文明が重要になってから追加する。

## アタックステップ

ターンプレイヤーは、攻撃できるアンタップ状態のクリーチャーで攻撃できる。

攻撃対象:

- 相手プレイヤー
- タップされている相手クリーチャー

相手プレイヤーを攻撃した場合:

- 相手にシールドがあるなら、シールドを1枚ブレイクする。
- 相手にシールドがないなら、攻撃したプレイヤーが勝つ。

クリーチャーを攻撃した場合:

- パワーを比べる。
- パワーが低い方のクリーチャーを破壊する。
- 同じなら両方を破壊する。

## エンドステップ

ターン終了時の効果を処理する。

その後、ターンを相手に渡す。

## 勝敗

プレイヤーは次の場合に勝つ。

- シールドがない相手プレイヤーに攻撃を通した。

プレイヤーは次の場合に負ける。

- 山札がない状態でカードを引く必要がある。

未決定:

- 初期 Genesis に特殊勝利条件を入れるべきか。

v0 では入れない。

## プロトタイプ設計ルール

最初のカードプールは、効果をシンプルにする。

初期に入れてよい効果:

- カードを引く
- 一定パワー以下のクリーチャーを破壊する
- クリーチャーをタップ、アンタップする
- クリーチャーのパワーを上げる
- クリーチャーを手札に戻す
- カードをマナに置く

初期に避ける効果:

- 無限ループ
- サーチが多い効果
- 複雑なタイミングを隠し持つ効果
- 1枚で勝つ効果
- UI が正解ルートを提案しないと扱いにくい効果

## テスト目標

最初のプレイテストでは、次を確認する。

- マナの判断は意味があるか。
- シールドは逆転の緊張を生むか。
- 攻撃は本当に判断になっているか。
- カードの強さだけではなく、選択で勝っているか。
- 元になったゲームに近すぎるのか、良い形で受け継げているのか。
- Genesis として進化させるべきルールはどこか。
