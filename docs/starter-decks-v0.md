# Genesis スターターデッキ v0

最初のテスト用スターターデッキ。

どちらも40枚。

## Deck A: 火自然アグロ

狙い:

早い攻撃とマナ加速で、相手にシールド判断を迫る。

確認したいこと:

- 攻める側がいつシールドを割るか悩めるか。
- マナに置くカードの判断が面白いか。
- 大型Wブレイカーが決め札として強すぎないか。

## Deck B: 水光コントロール

狙い:

守りながら手札を整え、相手の攻撃テンポを崩してから反撃する。

確認したいこと:

- 守る側がただ耐えるだけにならないか。
- ブロッカーが攻撃判断を面白くするか。
- 手札補充が強すぎないか。

## 最初のバランス確認

1戦目:

- 先攻ドローあり
- 文明一致なし
- 盤面上限なし

2戦目:

- 先攻後攻を入れ替える

3戦目:

- 先攻ドローなしを試す

見ること:

- 火自然が速すぎるなら、ブロッカーか軽量除去を増やす。
- 水光が固すぎるなら、火自然の突破手段を増やす。
- Wブレイカーが強すぎるなら、枚数かコストを調整する。
- 手札補充が強すぎるなら、水のドロー枚数を減らす。
