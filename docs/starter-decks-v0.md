# Genesis スターターデッキ v0

最初のブラウザプロトタイプ用スターターデッキ。

どちらも40枚。

## Deck A: 火自然アグロ

狙い:

早い攻撃とマナ加速で、相手にシールド判断を迫る。

確認したいこと:

- 攻める側がいつシールドを割るか悩めるか。
- マナに置くカードの判断が面白いか。
- 小型除去とパンプが、ブロッカー突破の判断を作れるか。
- 大型Wブレイカーが決め札として強すぎないか。

### 使い方の目安

序盤は軽量クリーチャーとスピードアタッカーで攻める。

中盤は除去やパンプでブロッカーを越える。

マナ加速できたら、Wブレイカーで一気にシールドを削る。

## Deck B: 水光コントロール

狙い:

守りながら手札を整え、相手の攻撃テンポを崩してから反撃する。

確認したいこと:

- 守る側がただ耐えるだけにならないか。
- ブロッカーが攻撃判断を面白くするか。
- タップとバウンスが攻撃前の道作りになるか。
- 手札補充が強すぎないか。

## 最初のバランス確認

見ること:

- 火自然が速すぎるなら、水光の軽量ブロッカーかタップを増やす。
- 水光が固すぎるなら、火自然の突破手段を増やす。
- Wブレイカーが強すぎるなら、枚数かコストを調整する。
- 手札補充が強すぎるなら、水のドロー枚数を減らす。
